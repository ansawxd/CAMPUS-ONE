# CAMPUS ONE

Концепт цифрового деканата. Демонстрационный проект. Вуз: Университет цифровых технологий и инноваций (УЦТИ).
Стек: Next.js 15 + Prisma 6 + PostgreSQL 16.

## Что работает в демо

- Вход/выход (Argon2id, сессии в БД, CSRF-защита, лимит неудачных попыток)
- Главная: текущая и следующая пара, посещаемость, заявки, уведомления
- Расписание на неделю (у студента — группа, у преподавателя — свои пары)
- Дисциплины: часы, преподаватель, тип аттестации, оценки, посещаемость
- Справки: студент подаёт заявку, деканат меняет статус, видна история
- Новости, заметки (создание/удаление только своих), каталог, карта кампуса, профиль

## Запуск

```bash
docker compose up -d db          # PostgreSQL в Docker, порт 5433 (только localhost)
npm install
cp .env.example .env             # если .env ещё нет
npx prisma generate
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Открыть http://localhost:3000

## Если вход не работает

1. Запустите диагностику — она скажет, что именно не так и какую команду выполнить:
   ```bash
   npm run db:check
   ```
2. Самое частое решение — пересоздать демо-базу:
   ```bash
   docker compose up -d db
   npm run db:reset    # удалит данные, применит миграции и запустит seed
   ```
3. После изменения `.env` перезапустите `npm run dev`.

База из Docker слушает порт **5433**, чтобы не конфликтовать с PostgreSQL, установленным прямо в Windows (он занимает 5432).
В режиме разработки форма входа показывает конкретную причину ошибки сервера, полный текст — в терминале с `npm run dev`.
