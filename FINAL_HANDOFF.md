# FINAL HANDOFF — CAMPUS ONE

## Что готово для сборки и хостинга

- Next.js 15 App Router + Prisma 6 схема
- Auth (Argon2id, сессии, CSRF, middleware)
- Заявки (полный цикл студент → деканат)
- Новости (API + страница)
- Заметки (CRUD, только владелец)
- Каталог (ограниченные поля)
- Карта кампуса (демо)
- Уведомления (API, только владелец)
- Seed с двумя студентами и деканатом
- Документация: README, DEPLOYMENT.md

## Как получить рабочий проект

1. Скопируйте папку `campus-one/`.
2. Выполните шаги из `docs/DEPLOYMENT.md`.
3. Захостите как Node.js-приложение (не static export).

## Не включено в обязательное ядро

- Полный UI новостей с лайками/модерацией
- Заметки, карта кампуса, каталог
- e2e-тесты Playwright (конфиг есть, сценарии минимальны)
- Production-оптимизации и полная дизайн-система

Проект можно собрать (`npm run build`) и запустить после настройки PostgreSQL.
